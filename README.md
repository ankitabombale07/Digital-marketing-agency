## Installation


### Using XAMPP


1. Install XAMPP


2. Copy project folder into:


C:\xampp\htdocs\


3. Start Apache


4. Open browser:


PHP, JavaScript, SQL

## Contact Form Setup


Open:


includes/contact-process.php


Change:


info@digigrowth.com


to your actual email address.



## Live Hosting Setup


Upload all files into:


public_html/


Make sure:


- PHP version is 8+
- Mail function is enabled
- SSL certificate installed
